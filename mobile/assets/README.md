# Assets Directory

Este directorio contiene los recursos gráficos de la aplicación móvil.

## Archivos Requeridos

### Para App Icon
- `icon.png` - Icono principal de la aplicación (1024x1024 px)

### Para Splash Screen
- `splash.png` - Imagen de pantalla de carga (1284x2778 px)

### Para Android
- `adaptive-icon.png` - Icono adaptativo Android (1024x1024 px)

### Para Notificaciones
- `notification-icon.png` - Icono de notificaciones (96x96 px, fondo transparente)

### Para Web
- `favicon.png` - Favicon para versión web (32x32 px)

## Notas

Los iconos se generarán automáticamente con Expo cuando se haga el build.

Para generar iconos personalizados, usar:
```bash
npx expo-icon
```

O crear una cuenta en [Expo Icon](https://icon.expo.dev/)
